# Librería de sonidos InnovaSites (v2)

Efectos generados con ElevenLabs Sound Effects (eleven_text_to_sound_v3), 2 variaciones de cada uno (_a / _b), en WAV mono 44,1 kHz.
Se usan desde `audio.py` de cada Reel con `smp('nombre', ganancia)`. Alternar variaciones entre videos para que no suenen repetidos.

| Archivo | Uso |
|---|---|
| sfx_whoosh_a / _b | Transición entre escenas |
| sfx_impacto_a / _b | Golpe en momentos clave (título, sello, cierre) |
| sfx_pixel_a / _b | Pixel aparece / celebra |
| sfx_alerta_a / _b | Alerta, error, algo sospechoso |
| sfx_exito_a / _b | Check, respuesta correcta, regla cumplida |
| sfx_candado_a / _b | Candado que se rompe |
| sfx_datos_a / _b | Datos viajando |
| sfx_tecleo_a / _b | Escribir en pantalla |
